# Submission Checklist

- [ ] README explains setup, architecture, features, and limitations.
- [ ] Schema and data dictionary match the implemented database and CSV columns.
- [ ] Prompt history distinguishes reconstructed summaries from verbatim prompts.
- [ ] Dataset validation passes on the intended dataset.
- [ ] Backend tests pass.
- [ ] Frontend production build succeeds.
- [ ] Import testing uses a separate database.
- [ ] No credentials, environment secrets, local databases, or backup files are committed.
- [ ] Generated submission CSVs are current and their row counts are verified.
- [ ] Git changes are reviewed, committed, and pushed.
- [ ] Final validation report contains only verified results.
